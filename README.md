1. Vertical vs. Horizontal Software: Give one real-world business example of a Vertical package and one example of a Horizontal package, explaining how they differ in scope
Answer =Vertical Assit users within a specific specialised industry segment.
example: software that manages construction projects, tracks inventory in hospitals
 Horizontal performs a general function across a wide range of different businesses.
example accounting software, word processors spreadsheet packages or office automation tools.

2. Operating System Modes: Compare Batch Processing and Real-Time Processing. In what type of business or industrial scenario would each be used?
Answer = Batch processing is used in business that need to process large amounts of data at a scheduled time rather than immediately eg Banks to process many transactions and calculate interest
Real-time is used in businesses that need to process information immediately eg hospitals to monitor patient's heart rates and other vital signs
